# make-knowledge-cards 🧠

> Kimi Agent Skill — 将文章、笔记自动转换为结构化知识卡片。

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

---

## ✨ 核心特性

- **智能提取** — 从 `.md` / `.txt` 或粘贴文本中识别核心知识点
- **结构化输出** — 每张卡片含：标题、核心知识、简明解释、自测题
- **单点聚焦** — 一张卡片一个知识点，去重不堆砌
- **数量自适应** — 依据内容深度生成 5–8 张，不足不凑数
- **忠实原文** — 严格基于输入内容，不编造信息

---

## 📦 安装

```bash
git clone https://github.com/Yuzhe-XU1/article-to-knowledge-cards.git
cp -r article-to-knowledge-cards/skills/make-knowledge-cards ~/.config/kimi/skills/
```

验证：在 Kimi 中输入 `请帮我将这篇文章转换成知识卡片`

## 🚀 使用

| 方式 | 操作 |
|------|------|
| 粘贴文本 | 发送提示词 → 粘贴文章内容 |
| 本地文件 | `请将 /path/to/notes.md 转换成知识卡片` |

**常用提示词：**
- `请帮我将这篇文章转换成知识卡片`
- `请从以下内容中提取核心知识点，生成学习卡片`
- `请帮我把这篇复习材料整理成知识卡片，方便记忆`

## 输入输出示例

**输入（生物学）：**
```
光合作用是指绿色植物利用光能，把二氧化碳和水转化成储存能量的有机物，
并且释放出氧气的过程。光合作用分为光反应和暗反应两个阶段...
```

**输出：**
```markdown
### 卡片 1：光合作用的定义
- **核心知识**：绿色植物利用光能将 CO₂ 和 H₂O 转化为有机物并释放 O₂
- **简明解释**：植物制造有机物的基础代谢过程，为地球生命提供能量和氧气
- **自测**：为什么光合作用对地球生态系统至关重要？

### 卡片 2：光反应
- **核心知识**：光合作用第一阶段，在类囊体薄膜上进行，需要光照
- **简明解释**：将光能转化为化学能，生成 ATP 和 NADPH
- **自测**：光反应的产物是什么？（答：ATP 和 NADPH）

### 卡片 3：暗反应
- **核心知识**：光合作用第二阶段，在叶绿体基质中进行，不直接需要光
- **简明解释**：利用 ATP 和 NADPH 将 CO₂ 固定并还原为糖类
- **自测**：如果光反应停止，暗反应能否长期进行？（答：不能）
```

> 内容不足时（如仅一句"Docker 是一个开源的容器化平台"），只生成 1 张卡片，不强行凑数。

## 限制与说明

| 功能 | 状态 | 替代方案 |
|------|------|---------|
| 网页抓取 | ❌ 暂不支持 | 粘贴文本或提供本地文件 |
| PDF 读取 | ❌ 暂不支持 | 提取文本后粘贴 |
| Anki 导出 | ❌ 暂不支持 | Markdown 输出，可手动导入 |
| 图形界面 | ❌ 暂不支持 | Kimi 对话界面交互 |
